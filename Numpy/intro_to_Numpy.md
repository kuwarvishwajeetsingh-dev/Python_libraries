``` NumPy (Numerical Python)```

```Theory```

NumPy is used for fast mathematical work on arrays.
The core object is the ndarray (n-dimensional array).
Why not a Python list?
A NumPy array is faster (stored in contiguous memory, written in C).
It uses less memory.
It supports vectorized operations, so there are no loops (a + b works on whole arrays).
A list is heterogeneous (mixed types), but an array is homogeneous (one data type).
