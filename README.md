# 🐍 Python Library Examples

A beginner-friendly collection of hands-on examples for popular Python libraries. Each folder focuses on one library, with small, runnable scripts that show the core concepts.

## 📁 Repository Structure

| Folder | What's inside |
|--------|---------------|
| `Numpy/` | Arrays, indexing, slicing, broadcasting, math operations |
| `pandas/` | Series, DataFrames, data cleaning, filtering, groupby |
| `Matplotlib/` | Line, bar, scatter, pie and histogram plots |
| `GUI Tkinter/` | Desktop GUI apps: windows, buttons, labels, entry fields, layouts |

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- pip

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/kuwarvishwajeetsingh-dev/<repo-name>.git
   cd <repo-name>
   ```

2. Install the required libraries
   ```bash
   pip install numpy pandas matplotlib
   ```
   > Tkinter comes pre-installed with Python on Windows and macOS. On Linux: `sudo apt install python3-tk`

3. Run any example
   ```bash
   python Numpy/<filename>.py
   ```
